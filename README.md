# grove

Grove holds kodhama's agent supervision skills (`project-lead`,
`story-worker`, `supervision-setup`, `session-restart` and `context-gauge`)
and the receipt checker that goes with them, moved here from
`kodhama/math-quest`, to be shipped as one plugin for Claude Code and Codex.
The skills and their tests are here; packaging them as a plugin is the next
step, tracked as GRO-6.
